# Sprint 025 — Reviewed engineering handoff

Goal: establish the first reusable, truthful engineering coordination step without duplicating support or identity.
Scope: portable versioned contract/project registry; founder-only reviewed brief preparation; current open-ticket revision binding; digest-only audit; founder ticket UI with explicit copy and disabled execution status. Original ticket narrative and school/reporting identity excluded.
Out of scope: automated investigation, persistent task execution, AI spend, repository mutations, new staff roles, Paperclip installation, production repairs and other-project connections.
Acceptance: non-founder, unsigned, cross-site, stale and closed-ticket requests fail; unexpected contract fields fail; repeated preparation is deterministic; changing source/draft clears preview; UI discloses ephemeral storage, manual privacy review and disconnected runner. No reporter/public event or proposal is created by preparing a handoff.
Validation: contract and policy tests; HTTP denial before storage; database test for revision, privacy and audit minimization; typecheck/lint/build, full CI, synthetic browser form/phone-width checks. See ADR 0010 for the subsequent isolated-runner stages.
