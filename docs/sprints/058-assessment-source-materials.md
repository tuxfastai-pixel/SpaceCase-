# Sprint 058 — teacher assessment source materials

Goal: accept teacher question papers, handwritten pages, memoranda and supporting files separately from learners' submitted work. Offer camera/bulk images, PDF, DOCX and legacy DOC; crop/rotate and reversible scan cleanup locally; retain private source attachments under teacher/current-class authority. Produce a printable scan PDF and teacher-reviewed editable Word text. A scan enhancement must never be labelled OCR or verified transcription.

Before saving an assessment, files remain a bounded local queue with an unsaved warning. After a draft is saved, explicit upload stores private objects and bounded SQL metadata. Immutable upload IDs/hashes resume uncertain results; assessment locks enforce source quotas. Original uploaded image preparation strips location metadata. A teacher can inspect the selected original locally before applying a cleaned variant. Raw PDF/Word files are download-only, never rendered as trusted HTML or served publicly. File signatures and bounded DOCX structure are checked; this is not a malware certification. No learner matching, marks, roles, AI/Atlas transfer, email sending or provider activation follows an upload.

Digitization has two distinct outcomes: (1) cleaned image/PDF scans; (2) editable text, manually checked by the teacher and exported to Word. Bounded DOCX text extraction is possible without AI. Automatic handwriting/scanned-PDF OCR needs an approved PSG source-reading contract/provider, uncertainty evaluation, provenance and teacher review; current AI gates remain off, and UI must state this limitation. Do not fabricate extracted text, answer keys, marks or handwriting accuracy.

Acceptance: current teacher+owner scope on every source list/upload/read/text edit; independent school/class/owner denial; no learner-page pollution; limits, bad signatures, invalid ZIP/encryption/expansion bounds rejected; interrupted uploads retry same content; stale transcript revisions fail; image cleanup stays reversible before upload; scan PDF and DOCX are valid downloadable documents. Full CI migrations/typecheck/lint/tests/build plus synthetic browser checks before release. Apply additive migration only after isolated verification; no production learner fixtures. Register SOURCE-01/OCR-01 and existing QA-04/AI-01. Production storage/first real camera/document flow must be checked separately.

Source-only drafts contain an empty rubric, not invented questions or marks. Migration 0018 atomically replaces the prior minimum-one rubric check with a stage-aware invariant: zero questions only in DRAFT; OPEN still requires 1–50. The server also rejects OPEN before a complete rubric. Existing populated assessments remain valid.
